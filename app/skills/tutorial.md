# Tutorial: a step-by-step guide

The viewer wants to do this themselves after watching, so every step counts.

- Open with the result they'll have at the end ("In 90 seconds you'll have X running").
- Show every step in order, one visible action per step, and the result after each one.
  Don't skip a step the viewer needs to copy.
- Say why a step is needed in a few words, not only what it does.
- Show commands and the text typed in real time so they can be read and copied.
- Installs, downloads, builds and other waits: fast-forward them and say what's happening
  ("this takes a few seconds"). Page loads: cut straight to the loaded page.
- End on proof that it worked (the output, the page, the file), then a one-line recap.
- Tone: friendly teacher, plain words, no hype.
